# ✨ Typography Best Practices

- Use one font family throughout the site for a clean identity.
- Keep line lengths between 60–75 characters.
- Use bold text only for emphasis.
- Add generous spacing between sections.
- Use smooth scroll and subtle animations to complement the typography.
- Maintain consistent font sizes and weights across all pages.
